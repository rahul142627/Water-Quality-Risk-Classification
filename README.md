# Water Quality Risk Classification

## Overview
An end-to-end machine learning prototype built for environmental monitoring as part of the 10-day Capstone project. It classifies water samples into safe or high-risk categories using core physicochemical indicators[cite: 1].

## Features
- **Exploratory Data Analysis & Handling Missing Data**: Automated imputation and outlier management.
- **Foundational Machine Learning**: Decision Tree classification pipeline optimized for zero-cost execution[cite: 1].
- **Interactive UI**: Lightweight Streamlit application for real-time predictions[cite: 1].
